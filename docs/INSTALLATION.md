## Prerequisites

### Hardware Requirements
- **CPU**: 2 cores minimum (4 cores recommended for transcoding)
- **RAM**: 4GB minimum (8GB recommended)
- **Storage**: 100GB+ for media storage
- **Network**: Stable internet connection with port forwarding capability

### Software Requirements
- Debian 13 (or compatible Debian-based distribution)
- Sudo privileges
- Internet connection
- Git (for cloning repository)
